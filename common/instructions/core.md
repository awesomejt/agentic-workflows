# Core Agent Instructions

- Treat the active repository's instructions as authoritative for that scope.
- Inspect current files and state before relying on remembered context.
- Preserve user changes and keep unrelated work out of the task.
- Make focused, reviewable changes and validate the behavior that changed.
- Do not expose credentials, private keys, tokens, raw transcripts, or private
  runtime state.
- Record durable decisions where the repository expects them and use its
  authoritative task system for task state.
- Ask before expanding into production changes, external communication,
  destructive operations, or unrelated systems.
- Report concrete outcomes, validation evidence, open risks, and follow-up work.
